# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report privately, either way works:

- GitHub: the "Report a vulnerability" button on the repository's Security tab.
- Email: alexeydinozavrikov@proton.me

Include what you found, how to reproduce it, and the version (see the page footer or `CHANGELOG.md`).

Meridian is maintained by one person. I aim to acknowledge a report within 7 days and will keep you informed about the fix. Please give me reasonable time to ship it before disclosing publicly.

## Scope

In scope: this repository's code and its deployment scripts.

Please do not run automated scans or load tests against the live service, and do not access or modify other people's data while testing. A local instance (see the README) is the right place to experiment.

## Supported versions

Only the latest release receives security fixes.
